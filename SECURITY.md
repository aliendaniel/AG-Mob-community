# Security Policy

Please do not report security or privacy issues through public GitHub Issues, public Discussions, Discord, or social media.

Send private security reports to:

`SECURITY_EMAIL`

## What To Include

- Short description of the vulnerability or privacy risk
- App version, device, and iOS/iPadOS version
- Gateway connection type if relevant
- Reproduction steps or a minimal proof of concept
- Possible impact
- Screenshots, recordings, or logs if safe and redacted
- Your contact information for follow-up

Please redact real user data, setup codes, device tokens, API keys, private logs, and other sensitive information whenever possible.

## Scope

Use the security email for vulnerabilities, privacy risks, credential exposure, permission bypass, data leakage, or abuse paths.

Use GitHub Issues or Discussions for regular bugs, usage questions, and feature requests.

请发送邮件到：

`SECURITY_EMAIL`

普通 Bug、使用问题和功能建议请使用 Issues 或 Discussions，不要发送到安全邮箱。
