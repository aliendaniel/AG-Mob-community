# Contributing

Thank you for helping improve OpenClaw Mobile.

This repository is a public community and support hub, not the app source-code repository. Most contributions should be clear bug reports, usage questions, product ideas, documentation fixes, and high-signal feedback.

## Choose The Right Place

- Bug: open a GitHub Issue with the Bug form.
- Usage question: post in Discussions / Q&A.
- Feature idea: post in Discussions / Ideas.
- General topic: post in Discussions / General.
- Security issue: email `aliendaniel@hotmail.com` privately.

## Before Posting

Please search existing Issues and Discussions first.

For bug reports, include device, app version, OS version, connection type, reproduction steps, expected result, actual result, and safe attachments.

For feature ideas, describe the user problem, the workflow you want, alternatives you considered, and why it matters.

## Pull Requests

Small documentation fixes are welcome. Please keep PRs focused.

Do not submit app source code, build files, signing assets, setup codes, credentials, private logs, or private roadmap information to this repository.
