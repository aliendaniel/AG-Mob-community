# AG Mob Community & Support

[English](README.md) | [中文](docs/zh-CN/README.md)

AG Mob is an independent companion app for a user-owned OpenClaw-compatible Gateway. It helps you connect from iPhone or iPad, browse chats and scheduled tasks, follow live assistant runs, review readable results, approve actions when needed, and keep working when the connection is temporarily offline.

This repository is the public community and support hub. It is not the private app source-code repository.

AG Mob is developed and published by Chengling Hua as an independent individual developer. It is not affiliated with, endorsed by, or published by the OpenClaw project or its maintainers. The word "OpenClaw" is used only to describe compatibility with Gateway instances that users own or have permission to access.

## What You Can Do

- Connect to an OpenClaw-compatible Gateway with a setup code, QR scan, direct host, LAN, Tailscale, or secure URL.
- Browse chat sessions with clear run states, recent previews, unread counts, pinned sessions, and model/thinking metadata.
- Open a chat to follow grouped assistant runs, process steps, tool activity, final answers, tables, attachments, and long-reader views.
- Manage scheduled tasks, reminders, recurring runs, and chat append workflows from the Tasks tab.
- Search chats, messages, attachments, and tasks from one place.
- Tune language, notifications, device permissions, model, agent, reasoning mode, cache, and diagnostics.
- Continue reading cached content while offline; queued messages recover after the Gateway reconnects.

## Getting Started

### 1. Install The App

Install AG Mob on your iPhone or iPad from its App Store listing when it becomes available. Beta testers should use the invitation link provided directly by the maintainer.

### 2. Prepare Your Gateway

AG Mob connects to an OpenClaw-compatible Gateway instance that you own or have permission to use. The first connection usually starts with a setup code generated by that Gateway.

Good connection options:

- Same local network with a host such as `192.168.x.x`
- Tailscale address such as `100.x.x.x` or a `ts.net` domain
- Secure hosted URL using `https://` or `wss://`

### 3. Connect From The App

1. Open AG Mob.
2. Tap **Scan Setup Code**, or paste the setup code manually.
3. Give the Gateway a recognizable name.
4. Confirm Host / URL and Port.
5. Tap **Save and continue**.
6. Approve the device from the Gateway side if approval is required.

After pairing, reconnects prefer the saved device token. You should not need to scan the setup code every time.

### 4. Use Chats

The **Chats** tab shows your recent sessions. Each row includes the title, last activity, source, agent, model, thinking mode, and run status.

Useful actions:

- Tap a chat to continue it.
- Tap **New chat** to start a new session.
- Long-press a chat to rename, pin, mute task updates, reset context, or delete it from the mobile list.
- Use **Search** to find chats, messages, attachments, and tasks.

### 5. Follow Live Runs

Inside a chat, AG Mob keeps the run readable:

- Your message stays grouped with the assistant response.
- Process steps can be expanded or collapsed.
- Final results are separated from process details.
- Tables, long text, code, actions, diagnostics, and attachments can open in reader views.
- Approval cards stay visible when a human decision is required.

### 6. Manage Tasks

The **Tasks** tab is for scheduled runs, reminders, and chat append workflows.

You can:

- Filter tasks by **All**, **Enabled**, or **Paused**.
- Open a task to inspect recent runs and latest results.
- Run a task once immediately.
- Pause or resume a task.
- Create a new task from the Tasks tab or from supported chat actions.

### 7. Adjust Settings

Open **Settings** to manage:

- Current Gateway and reconnect testing
- Interface language: System, Chinese, or English
- Notifications for run completion, approvals, failures, and recovery
- Camera, microphone, photos, files, and location permissions
- Cache, privacy, diagnostics, and offline recovery

AG Mob requests device permissions only when needed. Location is used only when you explicitly attach your current location to a chat.

## Troubleshooting

### Gateway Cannot Connect

- Confirm the Gateway is running.
- Check Host / URL and Port.
- If you use LAN, make sure the phone and Gateway are on the same network.
- If you use Tailscale, confirm both devices are online in the same tailnet.
- If you use `https://` or `wss://`, confirm the certificate and reverse proxy are working.
- Open Settings and tap **Test connection again**.

### Waiting For Approval

The Gateway may require approval for a new device. Approve the device on the Gateway side, then return to the app. The app will continue once approval is complete.

### Messages Are Queued

If the Gateway is offline or a run is already active, new input may be queued. Keep the app open or reconnect later; queued messages are recovered after the Gateway is available.

### Notifications Do Not Appear

Check notification permission in iOS Settings and in the app's Settings page. Some beta or review builds may use local/native notification identifiers before production push configuration is complete.
