# AG Mob Community & Support

欢迎来到 AG Mob 的公开社区与支持仓库。

这里用于收集用户反馈、发布产品更新、维护已知问题、回答使用问题和整理社区资料。这里不包含 App 源码，也不用于提交代码贡献。

## 快速入口

- 报告 Bug：请使用 [Issues](../../issues) 中的 Bug 表单。
- 使用问题：请到 [Discussions / Q&A](../../discussions/categories/q-a) 提问。
- 功能建议：请到 [Discussions / Ideas](../../discussions/categories/ideas) 分享想法。
- 产品公告：请查看 [Discussions / Announcements](../../discussions/categories/announcements)。
- 普通交流：请到 [Discussions / General](../../discussions/categories/general)。
- 实时交流：加入 Discord：`DISCORD_INVITE_URL`。
- 安全问题：请私下发送邮件到 `SECURITY_EMAIL`，不要公开发布。

## 下载与支持

## 版本更新与已知问题

版本更新和已知问题会发布并置顶在 GitHub Discussions 中。维护草稿保存在：

- [Start Here 草稿](docs/community/seed-posts/start-here.md)
- [Known Issues 草稿](docs/community/seed-posts/known-issues.md)
- [Release Notes 草稿](docs/community/seed-posts/release-notes.md)
